# coracaosentimentos

Caminho de boas lembranças!
a cabeça guarda histórias que o tempo não desfaz,
Entre o riso guardado e o silêncio que traz a paz.
Viver é esse eterno reencontro com o que fomos,
E descobrir, no afeto, a grandeza do que somos.
Partilhar a jornada é acender uma nova luz,
Dividir o peso da mala que a vida conduz.
Relembrar os bons momentos, a curva do sorriso,
Fazer de um simples instante o nosso paraíso.
