# ❤️ Coração Sem Sentimentos

## Sobre o projeto

**Coração Sem Sentimentos** é um projeto desenvolvido para representar uma experiência relacionada a sentimentos, relacionamentos e emoções.

## Objetivo

O objetivo do projeto é criar uma aplicação com uma identidade visual marcante e uma experiência simples e intuitiva para o usuário.

## Tecnologias utilizadas

* HTML
* CSS
