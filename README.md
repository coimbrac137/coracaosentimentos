# coracaosentimentos


## Do fundo do coração!

Às vezes a gente esquece, mas as coisas mais importantes da vida são simples:
um abraço na hora certa, uma palavra de incentivo, um "tô aqui" quando
o mundo parece desabar. Este projeto é sobre isso — sobre sentir, sobre
compartilhar, sobre deixar um pedacinho da gente no mundo.

Que cada linha de código aqui carregue um pouco de carinho.
